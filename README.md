---

## helloProject
> Just a basic `"Hello World!"` console type of project.

## primitiveDataTypesProject
> Testing with primitive data types such as `i8` to `i128`, `isize`, `u8` to `u128`, `usize`, `f32`/`f64`, `bool` and `char`.

## compoundDataTypesProject
> Testing with compound data types and the concept of borrowing. Includes basic usage of arrays, tuples, slices, the `&str` and `String` types.
> 
> Also treats with basic mutation and reassignment of owned and borrowed variables.

## functionsProject
> Testing with functions, return values, and string formatting. Covers function parameters, the difference between expressions and statements, and basic math functions like BMI calculation.

## ownershipProject
> Exploring Rust's ownership system, borrowing, and references. Covers the three ownership rules, memory safety without a garbage collector, and the concepts of value moves and scope-based dropping.
